# To-Do List Web Application (Python Flask)

A simple, elegant, and pastel-themed To-Do List web application built using Python Flask and SQLite.  
It allows users to create, update, complete, and delete tasks while organizing them using priority levels visualized with minimal colored dots.

---

## 🔧 Features

- Add, edit, complete, and delete tasks  
- Priority selection (Low, Medium, High)  
- Minimal colored priority indicators  
- Clean pastel UI for a smooth user experience  
- SQLite database for storing tasks  
- Fully responsive layout  

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Bootstrap  
- **Backend:** Python, Flask  
- **Database:** SQLite  
- **Version Control:** Git & GitHub  

---

## 🚀 How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/todo-app.git
2. Move into the project directory:
```
   cd todo-app
```

3. Create and activate virtual environment:
```
   python -m venv venv
   venv\Scripts\activate
```

4. Install dependencies:
```
   pip install -r requirements.txt
```

5. Run the Flask app:
```
python app.py
```

6. Open in browser:
```
http://127.0.0.1:5000
```
